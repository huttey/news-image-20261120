THE WORLD — one image summing up Friday 20 November 2026: Russian missiles
hit Kyiv's bridges and cross into Poland, Cyclone Akvan makes landfall, COP31
talks deadlock on the final day, an AI sell-off drags Wall Street down
(S&P 500 −3.7%, Nasdaq −5.3%), the UK and EU agree a reset deal — plus the
world court's genocide ruling, the Nvidia SEC probe, the Hormuz tanker
incident and a 60.7% cancer trial. The image is drawn programmatically
(`draw.py`, Python/Pillow, DejaVu fonts) so every letter stays crisp and
legible, and `main.ts` copies the finished `entry.png` to `/output` byte
for byte on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
